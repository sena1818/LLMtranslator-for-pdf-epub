# 翻译质量裁判 Prompt

裁判模型：Gemini（与选手 DeepSeek 异源）。量表 1~5 分。
维度定义：

- **准确性 accuracy**：译文是否忠实传达原文命题、论证与语气，无漏译、错译、臆造。
- **流畅度 fluency**：中文是否自然通顺、符合学术/技术写作习惯，无翻译腔与语病。
- **术语一致性 terminology**：给定术语表的术语是否按规定译名翻译，全文用词是否统一。

裁判必须只输出 JSON，不要输出任何其它文字。
